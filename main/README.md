# Customer Segmentation Analysis Using SQL

## Business Problem

The objective of this project was to identify high-value, loyal, new, and at-risk customers using transaction data. The analysis helps businesses improve customer retention and make data-driven marketing decisions.

---

## Dataset

- UCI Online Retail Dataset
- 500,000+ transactions
- Customer purchase history

---

- MySQL
- SQL
